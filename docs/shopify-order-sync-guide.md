# Shopify 订单同步教程

把 Shopify 店铺的订单同步到系统的审单列表。整个过程分两部分：先在 Shopify 创建一个应用拿到凭证，再到系统后台添加店铺。

| 步骤 | 在哪里操作 | 产出 |
| --- | --- | --- |
| 1. 创建应用并配置权限 | Shopify Dev Dashboard | 一个已发布版本的应用 |
| 2. 安装应用 | Shopify Dev Dashboard | 应用装到目标店铺 |
| 3. 复制凭证 | Shopify Dev Dashboard | Client ID、Client Secret |
| 4. 添加店铺 | 系统后台 → 第三方商城 | 授权状态「已连接」 |
| 5. 同步历史订单（可选） | 系统后台 → 第三方商城 | 历史订单进入审单列表 |
| 6. 配置商品元字段（可选） | Shopify 店铺后台 | 自动补全品名、SKU、归属人 |

## 开始之前

- 你需要有 Shopify 店铺所在组织的 Dev Dashboard 访问权限。
- 应用和店铺必须属于**同一个 Shopify 组织**，否则系统无法获取访问令牌。
- 你需要有系统后台「第三方商城」的新增权限。

> Shopify 自 2026 年 1 月 1 日起不再支持在店铺后台新建自定义应用，因此本教程只介绍 Dev Dashboard 方式。

---

## 第一部分：在 Shopify 创建应用

### 1. 创建应用

1. 打开 [Shopify Dev Dashboard](https://dev.shopify.com/dashboard/)。
2. 在左侧导航选择 **Apps**。
3. 点击右上角 **Create app**，选择 **Start from Dev Dashboard**。
4. 输入应用名称（名称不限，例如 `Order Sync`），点击 **Create**。

### 2. 配置权限并发布版本

1. 进入应用的 **Versions** 页面，新建一个版本。
2. **App URL** 没有实际用途，填店铺地址或任意可访问的地址即可。
3. **Webhooks API version** 选最新版本。
4. 在 **Scopes** 中填入需要的权限：

   | 权限 | 是否必选 | 用途 |
   | --- | --- | --- |
   | `read_orders` | 必选 | 读取订单 |
   | `read_products` | 推荐 | 读取商品元字段，用于补全品名、SKU 和归属人 |
   | `read_all_orders` | 按需 | 同步 60 天以前的历史订单 |

   三个都要时，填写 `read_orders,read_products,read_all_orders`。

5. 点击 **Release** 发布版本。

> 没有 `read_all_orders` 时，Shopify 只返回最近 60 天的订单，更早的订单同步不到，也不会报错。

### 3. 安装应用到店铺

1. 在应用首页的 **Installs** 卡片中点击 **Install app**。
2. 选择要同步订单的店铺。
3. 点击 **Install**。

### 4. 复制 Client ID 和 Client Secret

1. 进入应用的 **Settings** 页面。
2. 复制 **Client ID** 和 **Client secret**，下一步要用。

> Client Secret 等同于密码，不要发到聊天群或写进文档。

---

## 第二部分：在系统中添加店铺

### 5. 添加 Shopify 店铺

1. 进入系统后台的 **第三方商城** 页面，点击 **添加**。
2. **商城类型** 先选 **SHOPIFY**，表单会切换为 Shopify 的字段。
3. 按下表填写：

   | 字段 | 填写内容 |
   | --- | --- |
   | 店铺名称 | 随意填写，会显示在订单来源里 |
   | HANDLE | 店铺地址 `xxx.myshopify.com` 中的 `xxx` |
   | Client ID | 第 4 步复制的 Client ID |
   | Client Secret | 第 4 步复制的 Client secret |
   | 币种模式 | 见下方说明 |

4. 点击 **保存**。

保存时系统会立即验证凭证：

- 验证通过：列表中授权状态显示 **已连接**，系统开始自动同步之后新增的订单。
- 验证失败：保存被拒绝并提示原因，店铺不会被添加。处理方法见 [常见问题](#常见问题)。

**HANDLE 怎么找**：登录 Shopify 店铺后台，浏览器地址形如 `admin.shopify.com/store/xxx`，其中的 `xxx` 就是 HANDLE。直接粘贴 `https://xxx.myshopify.com` 也可以，系统会自动截取。注意不要填店铺绑定的自定义域名。

**币种模式怎么选**：

| 选项 | 含义 | 适用情况 |
| --- | --- | --- |
| 店铺结算币种 | 按店铺设置的币种记录金额 | 店铺只用一种币种，或希望统一币种核算 |
| 订单展示币种 | 按客户下单时看到的币种记录金额 | 店铺开了多币种，希望保留客户实际支付的币种 |

### 6. 确认自动同步生效

1. 在 Shopify 店铺下一个测试订单。
2. 等待约 1 分钟。
3. 进入 **审单** 列表，用「订单平台 = SHOPIFY」筛选，应能看到这笔订单。

自动同步只处理**添加店铺之后**创建的订单。之前的订单需要按下一步手动同步。

### 7. 同步历史订单（可选）

1. 在 **第三方商城** 列表中，点击目标店铺操作列的 **订单同步**。
2. 选择订单创建时间的范围，系统会先显示该范围内的订单数量。
3. 确认后提交，任务在后台执行。
4. 在右上角 **任务中心** 查看进度。

订单较多时建议按月分批同步。重复同步同一时间段不会产生重复订单，已存在的订单会被更新。

### 8. 暂停或删除同步

- **暂停**：关闭列表中的状态开关，自动同步停止；重新打开后继续同步。
- **删除**：点击操作列的 **删除**，移除该店铺的同步配置。已同步的订单不受影响。

## 第三部分：用商品元字段补全订单（可选）

在 Shopify 商品上配置元字段后，同步订单时会自动带上中文品名、面单品名、SKU 编码和归属人。需要应用有 `read_products` 权限。

### 9. 创建元字段定义

1. 进入 Shopify 店铺后台 **设置 → 自定义数据 → 商品**。
2. 点击 **添加定义**，按下表逐个创建。命名空间和密钥必须与表中一致，类型都选 **单行文本**。

   | 字段名称 | 命名空间和密钥 | 作用 |
   | --- | --- | --- |
   | 中文品名 | `xyz.cn_product_name` | 订单商品的中文品名 |
   | 面单品名 | `xyz.waybill_product_name` | 打印面单时使用的品名 |
   | 归属人账号 | `xyz.owner_telephone` | 归属人的登录手机号 |
   | 归属人 | `xyz.owner_name` | 归属人的名字 |
   | 高优先级 SKU 编码 | `xyz.sku_code_high` | 覆盖商品自身的 SKU 编码 |
   | 备用 SKU 编码 | `xyz.sku_code` | 商品没有填 SKU 时使用 |

   按需添加，不需要的可以不建。

### 10. 在商品上填写元字段

打开商品详情页，在页面底部的元字段区域填写对应的值并保存。之后同步的订单会自动使用这些值。

### 补全规则

**SKU 编码**按以下顺序取第一个有值的：

1. 元字段 `sku_code_high`
2. 商品规格上填写的 SKU
3. 元字段 `sku_code`

取到编码后，系统先在店铺归属人所在部门的 SKU 中匹配；部门下一个都没匹配到时，再在归属人名下的 SKU 中匹配。编码区分大小写。匹配不到时订单照常同步，只是 SKU 名称为空。

**订单归属人**按以下顺序确定，从订单里第一个商品的元字段读取：

1. `owner_telephone` 对应的系统用户
2. `owner_name` 对应的系统用户
3. 添加店铺的人（默认）

## 支付状态对照

| Shopify 状态 | 系统状态 |
| --- | --- |
| `pending` | 处理中 |
| `authorized` | 已授权 |
| `partially_paid` | 部分付款 |
| `paid` | 已付款 |
| `partially_refunded` | 部分退款 |
| `refunded` | 已退款 |
| `voided` | 待付款 |

其它状态一律按 **待付款** 处理。

## 常见问题

### 保存时提示「无法获取Shopify访问令牌」

按顺序检查：

1. **HANDLE** 是否是 `xxx.myshopify.com` 中的 `xxx`，而不是自定义域名。
2. **Client ID** 和 **Client Secret** 是否完整复制，前后有没有多余字符。
3. 应用是否已经**安装**到这个店铺（第 3 步）。
4. 应用和店铺是否属于同一个 Shopify 组织。

### 保存时提示「无法连接到Shopify」

HANDLE 填错导致域名不存在，或服务器网络无法访问 Shopify。

### 授权状态显示「连接异常」

把鼠标移到标签上可以看到具体原因。

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 应用缺少订单读取权限(read_orders) | 应用版本没有勾选 `read_orders` | 在 Dev Dashboard 新建版本加上权限并发布，然后在系统中编辑店铺重新保存 |
| Client ID/Secret无效或应用权限不足 | Client Secret 被重新生成，或应用被卸载 | 确认应用仍已安装，编辑店铺填入新的 Client Secret 后保存 |

出现连接异常后店铺会被自动停用。修复后编辑并保存店铺，再把状态开关打开。

### 需要定期更新访问令牌吗

不需要。访问令牌有效期 24 小时，系统会在到期前自动更新。只有在 Shopify 重新生成了 Client Secret 时，才需要到系统里编辑店铺填入新的值。

### 编辑店铺时 Client Secret 是空的

出于安全考虑系统不回显 Client Secret。留空保存表示不修改，填写则替换为新值。

### 订单的收货人姓名、地址、电话是空的

这些字段属于 Shopify 的受保护客户数据。组织内自用的应用默认可以读取；如果同步到的订单缺少这些信息，到 Dev Dashboard 应用的 **API access requests** 中检查 **Protected customer data access** 是否已开通姓名、地址、电话和邮箱。

### 历史订单数量比 Shopify 后台少

应用没有 `read_all_orders` 权限时，只能读到最近 60 天的订单。加上权限并发布新版本后重新同步。

### 订单金额或币种不对

币种模式选择不当。编辑店铺调整币种模式，保存后重新同步受影响时间段的订单。

### 同步的订单找不到

1. 在任务中心确认同步任务已完成。
2. 在审单列表用「订单平台 = SHOPIFY」筛选。
3. 确认选择的时间范围覆盖了订单在 Shopify 的**创建时间**。
4. 订单可能已经审核通过，转入了正式订单列表。

### 订单没有中文品名或归属人不对

1. 确认应用有 `read_products` 权限。
2. 确认元字段的命名空间是 `xyz`，密钥与教程中的完全一致。
3. 确认元字段填在**商品**上，而不是商品规格上。
4. 归属人账号或名字在系统中找不到对应用户时，会使用添加店铺的人。

### 手动同步任务刚开始时显示「正在连接Shopline」

这是任务的通用提示文案，不影响同步，随后会变为同步进度。

### HANDLE 提示已被占用

同一个 HANDLE 只能添加一次，且 Shopify 与 Shopline 店铺共用这个限制。
