## 设计决定
- 项目已 `@EnableAsync`，但异步线程丢失 TenantContext 与 sa-token 会话（companyId 由 `BaseTenantEntity` 默认取当前租户），故**同步写入 + 全量 try/catch**，失败只 `log.warn`。
- `OrderResponse.convertEntity(TemporaryOrder, …)` 返回空对象（不含 platform），所以两个 `/page` 都改为先拿实体分页、按实体 `platform` 筛选，再映射响应。
- `/download` 为异步导出任务：在接口上增加重载 `record(action, orderType, orderIds, totalCount)`，三参版本委托给它（count = ids.size()）；totalCount 小于 ID 数时按 ID 数。

## 问题
- 导出日志在**提交时**按当前数据查询，异步任务实际导出的行可能因期间数据变化略有出入。
- 导出多查一次 Shopify 订单第一页（≤500 条实体），对超大导出提交接口有少量额外耗时。
