## 与契约的出入（详见最终报告）
- 订单页 8 单、行项目首屏 5 个（超出补查）：GraphQL 单次查询请求成本上限 1000 点，`first: 100` + 内联元字段不可行
- 元字段用 `metafields(first: 6, keys: ["xyz.<6 个已知 key>"])`，不是 `namespace: "xyz", first: 20`
- GraphQL 没有浏览器 UA（CustomerVisit 无 userAgent），转换后 UA 为空、平台 UNKNOWN
- landing_site/referring_site 取 `customerJourneySummary.lastVisit ?: firstVisit`（`landingPageUrl/referrerUrl` 已废弃）
- 客户邮箱/电话取 `defaultEmailAddress.emailAddress` / `defaultPhoneNumber.phoneNumber`（`email/phone` 已废弃）
- 行项目未查询 `discountedTotalSet`、`totalDiscountSet`（转换器不读，省成本；适配器支持映射 totalDiscountSet）
- `verifyAndUpdateAuthStatus` 直接 POST graphql.json，不经 ShopifyGraphqlClient（新建店铺无 id，客户端失败处理按 id 写库）
- 对账对已存在订单用 `isCustomerCancelled`（cancelled_at 非空或全部行项目移除），与凭证模式取消检查一致
- 执行器保存的 lastReconcileTime 取 max(返回值, since)，避免无订单时回看窗口让游标倒退
