本次更新覆盖以下版本区间：

- `ADMIN-V1.0.25` ~ `ADMIN-V1.0.28`
- `MALL-V0.0.2` ~ `MALL-V0.0.4`

## 管理后台

### 广告投放与像素

- 新增广告投放配置能力，子域名绑定商品时支持按平台、像素和落地页拆分配置。
- SPU 搜索下拉框对已绑定项置灰，并展示“已绑定”提示，减少重复绑定。
- 像素追踪列表转化事件展示优化为“中文（英文）”格式。
- 修正 Google Pixel 转化标签绑定逻辑。
- 调整像素访问令牌字段展示文案。
- 支持新增并绑定嵌入像素。
- 新增 Taboola、Bigo 像素平台支持。
- 优化像素转化跟踪逻辑，并避免风控页面触发像素事件。

### 域名与 DNS

- 子域名创建支持 `NUXT_MALL` 类型，创建时自动校验证书并写入 Nginx 配置。
- 新增 GoDaddy、Namecheap DNS 解析支持。
- Nginx 配置模板支持 `proxy_busy_buffers_size` 参数。
- 新增 `NUXT_MALL` 类型的 Nginx SSR 优化配置模板。
- 合并 Nginx 配置模板，并将 upstream 改为可配置。
- 修复子域名删除时误删 Nginx 配置的问题，并优化列表展示优先级。
- 修复添加子域名时页面全屏白色闪烁问题。

### 订单同步与商城管理

- 第三方商城新增币种模式配置，支持 `shop_money` 与 `presentment_money`。
- 第三方商城编辑表单增加币种模式选择器。
- Shopline 订单同步集成商品 Metafield 元字段。
- 修复 Shopline 订单同步中 `skuId` 始终为 0、新订单判断不准确、SKU 名称来源错误等问题。
- 同步游标改为原子 `UPDATE`，减少乐观锁冲突。
- 第三方商城启用软删除，`handle` 和 `token` 字段增加唯一约束。

### 后台体验与稳定性

- Token 使用记录表格增加提交用户列。
- 员工管理改为伪删除，并在删除前执行清理逻辑。
- 修复地址字段拼接逻辑，确保地址信息完整。
- 修复 Metafield 归属人查询的懒加载异常。
- 修复 Nginx 配置模板类型为空时未设置默认值的问题。
- 修复订单商品字段映射和 `BeanUtil` 类型转换异常。

## Mall 商城前台

### 购买链路

- 购买按钮组件支持在原按钮滚动不可见时展示底部悬浮购买栏。
- 悬浮购买栏支持三维度风格配置，便于不同商城模板按投放场景调整展示。
- 统一结算流程，移除直接下单模式，收银台价格加载增加骨架占位。
- 修复收银台表单输入框在窄容器下不自适应的问题。
- 修复购物车数量累加错误和商品名称字段错误。
- 修复规格选择样式溢出问题，并优化文字换行效果。
- 禁用手动输入地址配置项，收敛下单地址填写方式。

### 像素与投放

- 支持嵌入像素，并新增 Taboola、Bigo 像素能力。
- 优化 Google、Meta、TikTok 等像素转化跟踪逻辑。
- 避免风控页面触发像素事件，减少无效转化上报。
- 子域名绑定商品时支持广告投放配置，与管理后台投放能力联动。

### 路由、斗篷与性能

- 斗篷策略优先使用 SPU 投放设置，而不是一级域名配置。
- 收敛服务端中间件路由判断，清理调试日志。
- 增加统一路由匹配工具，优化商品页、落地页、结账页、订单页等中间件判断。
- 修复收银台价格查询全表扫描导致的明显延迟，并增加耗时诊断日志。
- 修复临时订单插入缺少 `is_reviewed` 字段导致下单失败的问题。

## 文档

- 初始化 V7 Shop 文档站点。
- 新增 Mall 商城模板使用教程。
- 新增第三方商城订单同步操作文档。
- 废弃操作手册下的旧发布文档，后续版本变更统一维护在更新日志中。
