# 商品管理

商城的核心是商品。系统使用 **SPU → 商品（Product）→ 规格（SKU）** 三层结构管理商品数据。

## 基本概念

| 概念 | 说明 | 示例 |
|------|------|------|
| SPU | 标准化产品单元，同一商品的抽象集合 | iPhone 16 |
| 商品（Product） | SPU 在特定国家/语言下的具体版本 | iPhone 16（美国/英语版） |
| 规格（SKU） | 商品的可购买单元，对应具体属性组合 | iPhone 16 黑色 128GB |

一个 SPU 下可以有多个商品，分别对应不同国家和语言，方便多站点复用。

## 1. 创建 SPU

进入管理后台，点击左侧菜单 **商品管理 → SPU 管理**。

1. 点击 **添加** 按钮
2. 填写 SPU 名称（内部标识，不对用户展示）
3. 选择商品分类
4. 保存

SPU 列表支持按标题搜索，点击行可展开查看该 SPU 下的所有商品。

### 公开状态

SPU 列表中有 **是否公开** 开关。只有公开的 SPU 才能被子域名绑定并在前台展示。

## 2. 新增商品

在 SPU 列表中，点击目标 SPU 行内的 **新增** 按钮，打开商品编辑弹窗。

### 2.1 基本信息

- **标题**：商品在前台展示的名称
- **摘要**：商品简要描述
- **商品描述**：富文本编辑器，支持图片、表格等

### 2.2 图片与视频

- **商品图片**：支持多图上传和拖拽排序，第一张为主图
- **商品视频**：可选，上传商品展示视频

### 2.3 价格

- **售价**：商品实际销售价格
- **原价**：划线价，用于展示折扣
- **成本价**：内部记录，不对外展示
- **利润 / 利润率**：根据售价和成本价自动计算（只读）

系统支持标准货币和业务货币双输入，自动联动汇率换算。

### 2.4 税费设置

如需收税，可开启 **是否收税** 并配置：

- 税费方式：固定金额 / 按金额比例 / 按数量
- 对应的税费金额或比例
- 免税门槛（可选）

### 2.5 库存（单规格）

当商品没有多款式时，直接在编辑页配置库存：

- **SKU**：从系统中选择或新建 SKU 编码
- **库存数量**：可售数量
- **条码**：可选
- **缺货后继续销售**：开启后库存为 0 时仍可下单

### 2.6 多款式（多规格）

如果商品有多种属性组合（如颜色 + 尺码），开启 **多款式** 功能：

1. 添加规格名（如「颜色」「尺码」）
2. 为每个规格添加规格值（如「黑色」「白色」；「S」「M」「L」）
3. 系统自动生成款式组合列表
4. 逐行填写每个组合的售价、库存、SKU 编码等

### 2.7 商品设置（右侧）

- **上架**：控制商品是否在前台展示
- **国家 / 语言 / 货币**：继承自子域名，通常不需要手动修改
- **SPU**：归属的 SPU（新增时自动关联）
- **商城主题**：该商品使用的主题模板
- **落地页模板**：该商品的落地页使用的模板

## 3. 复制与翻译

在 SPU 展开的商品列表中，每个商品支持：

- **复制**：基于当前商品快速创建另一个版本（如不同国家）
- **翻译**：将商品内容翻译到其他语言
