# 独立站模板使用教程

本教程面向外贸运营人员，介绍如何从零开始配置一个基于 **独立站模板** 的品牌站点。

独立站模板是一套多商品、支持购物车的外贸自建站前台模板，适用于需要展示多个 SPU / 多规格商品并通过购物车结算的场景。

## 整体流程

从域名到独立站上线，需要依次完成以下步骤：

1. **[域名配置](./domain-setup)** — 添加一级域名、创建子域名、绑定国家与语言
2. **[商品管理](./product-management)** — 创建 SPU，在 SPU 下新增商品（Product），配置规格与库存
3. **[主题设置](./theme-setup)** — 创建或复制主题模板，用页面设计器编辑页面，给子域名绑定主题
4. **[站点配置](./site-config)** — 设置网站名称、Logo、购物车模式、全局样式等
5. **[SPU 绑定与上线](./bindproduct-launch)** — 将 SPU 绑定到子域名，配置落地页，完成上线

:::tip 建议
建议按顺序操作。域名和商品是基础数据，主题和站点配置依赖它们。
:::
