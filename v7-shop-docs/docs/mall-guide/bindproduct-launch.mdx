# SPU 绑定与上线

完成域名、商品和主题配置后，最后一步是将 SPU 绑定到子域名，让商品在前台展示。

## 1. 进入绑定页面

在子域名列表中，点击目标子域名行内的 **站点配置** 按钮，进入 SPU 绑定与配置页面。

页面分为两部分：

- **左侧**：已绑定的 SPU 列表
- **右侧**：选中 SPU 的投放与落地页配置

## 2. 绑定 SPU

1. 在顶部搜索框中输入 SPU 名称或编码进行搜索
2. 选择目标 SPU
3. 点击 **绑定**

:::info 说明
- 只有已公开的 SPU 才可绑定
- 不支持当前子域名国家的 SPU 会显示为禁用状态
- 已绑定的 SPU 不会重复出现在搜索结果中
:::

## 3. 投放设置

选中左侧某个 SPU 后，右侧切换到 **投放设置** Tab：

- **广告平台**：选择 Meta / Google / TikTok
- **流量媒介**：选择流量来源
- **斗篷策略**：配置反爬/风控策略
- **活动名**：自动或手动生成广告活动名称

配置完成后点击 **保存配置**。

## 4. 像素追踪

切换到 **像素追踪** Tab，可以为已选广告平台添加或删除追踪像素。

## 5. 落地页配置

切换到 **落地页配置** Tab，可以分别设置三种场景的落地页：

| 场景 | 说明 |
|------|------|
| 真实用户 | 正常用户访问时看到的页面 |
| 风险用户 | 系统判定为风险用户时展示的替代页面 |
| 黑名单用户 | 被标记为黑名单的用户看到的页面 |

每种落地页支持：

- **预览**：查看当前落地页效果
- **复制广告链接**：获取该落地页的访问链接
- **主题**：打开设计器编辑该落地页的主题
- **模板**：应用主题模板
- **站点**：编辑该落地页的站点配置

## 6. 解绑 SPU

在左侧已绑定列表中，选择 SPU 后点击 **解绑**，即可将 SPU 从该子域名移除。

## 上线检查清单

在正式上线前，请确认以下事项：

- [ ] 一级域名已添加，DNS 解析已指向服务器
- [ ] 子域名已创建，SSL 证书已签发
- [ ] 子域名已绑定主题模板
- [ ] 站点配置已完善（网站名称、Logo、购物车模式等）
- [ ] SPU 已设为公开状态
- [ ] SPU 下的商品已上架，价格和库存已配置
- [ ] SPU 已绑定到子域名
- [ ] 通过浏览器访问子域名，确认页面正常展示
