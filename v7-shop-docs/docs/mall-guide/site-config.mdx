# 站点配置

站点配置控制独立站前台的全局行为和样式，包括网站信息、购物车模式、配色等。

## 进入站点配置

在子域名列表中，点击目标子域名行内的 **站点配置** 按钮，打开配置面板。

## 全局配置（globalConfig）

### 基本信息

| 字段 | 类型 | 说明 |
|------|------|------|
| 网站名称 | 文本 | 显示在页面标题和 Footer 中 |
| Logo | 图片 | 网站 Logo，显示在导航栏 |
| 网站图标 | 图片 | 浏览器标签页图标（Favicon） |
| 浏览器标签标题 | 文本 | 浏览器标签页显示的文字 |
| 标语 | 文本 | 网站标语 |
| 网站描述 | 多行文本 | 网站简介 |

### 联系方式

| 字段 | 类型 | 说明 |
|------|------|------|
| 联系邮箱 | 文本 | 显示在页脚或联系页面 |
| 联系电话 | 文本 | 联系电话 |
| WhatsApp | 文本 | WhatsApp 联系号码 |
| 地址 | 多行文本 | 公司/店铺地址 |
| 营业时间 | 文本 | 营业时间说明 |

### 版权与备案

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 版权声明 | © 2024 All rights reserved. | 页脚版权文字 |
| ICP 备案号 | — | 国内站点需要填写 |

### 社交媒体

支持配置以下平台链接，配置后前台页脚会自动展示对应图标：

Facebook、Twitter / X、Instagram、YouTube、TikTok、LinkedIn

### 邮件订阅

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 邮件订阅标题 | 订阅我们的新闻 | 订阅区域的标题文字 |

### SEO 设置

| 字段 | 说明 |
|------|------|
| SEO 标题 | 搜索引擎展示的页面标题 |
| SEO 描述 | 搜索引擎展示的页面描述 |
| SEO 关键词 | 逗号分隔的关键词 |

### 购物车与下单

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 启用数量选择器 | 开关 | 开启 | 关闭后每个规格只能选择 1 件 |
| 启用购物车功能 | 开关 | 开启 | 关闭后不显示「加入购物车」按钮，只显示「立即下单」 |
| 购物车模式 | 选择 | 单页模式 | **商城模式**：多商品购物车；**单页模式**：单商品直接结算 |
| 允许手动输入地址 | 选择 | 禁用 | 开启后用户可在结算页手动填写收货地址 |

:::tip 购物车与数量选择器的组合效果

| 数量选择器 | 购物车 | 效果 |
|-----------|--------|------|
| 开启 | 开启 | 每个规格可选多件，允许多个规格，显示「加入购物车」按钮 |
| 关闭 | 开启 | 每个规格只能 1 件，允许多个规格，显示「加入购物车」按钮 |
| 开启 | 关闭 | 每个规格可选多件，只允许一个规格，仅显示「立即下单」 |
| 关闭 | 关闭 | 每个规格只能 1 件，只允许一个规格，仅显示「立即下单」 |

:::

## 全局样式（globalStyle）

### 配色

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 主色 | `#3b82f6` | 按钮、链接等主要交互元素颜色 |
| 辅色 | `#64748b` | 次要元素颜色 |
| 成功色 | `#22c55e` | 成功状态提示 |
| 警告色 | `#f59e0b` | 警告状态提示 |
| 错误色 | `#ef4444` | 错误状态提示 |
| 页面背景色 | `#f8fafc` | 整体页面背景 |
| 表面背景色 | `#ffffff` | 卡片、弹窗等表面元素背景 |
| 主文字色 | `#1e293b` | 正文文字颜色 |
| 次要文字色 | `#64748b` | 辅助说明文字颜色 |
| 边框色 | `#e2e8f0` | 输入框、分割线等边框颜色 |

### 排版

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 字体 | Inter, -apple-system, BlinkMacSystemFont, sans-serif | 全站字体 |
| 基础字号 | 14px | 正文字体大小 |
| 行高 | 1.5 | 文字行高 |

### 圆角与间距

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 小圆角 | 4px | 小型元素（标签、徽章）的圆角 |
| 中圆角 | 8px | 中型元素（按钮、输入框）的圆角 |
| 大圆角 | 12px | 大型元素（卡片、弹窗）的圆角 |
| 间距单位 | 8px | 布局间距的基础单位 |
