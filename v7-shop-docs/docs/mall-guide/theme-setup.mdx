# 主题设置

主题模板决定了商城前台的页面布局和视觉风格。每个子域名需要绑定一个主题才能正常展示。

## 1. 管理主题模板

进入管理后台，点击左侧菜单 **网站管理 → 主题模板**。

页面以卡片网格展示所有主题模板，每张卡片包含：

- 模板封面图
- 模板名称和描述
- 共享类型：**私有** / **部门** / **公司**
- 归属人

### 创建主题

有两种方式创建主题：

**方式一：新建空白模板**

点击 **新建模板**，输入模板名称和描述，保存后得到一个空白主题。

**方式二：从已有模板复制**

点击 **从模板复制**，选择一个现有模板作为源，输入新名称，保存后得到一份副本。

:::tip 建议
如果已有配置好的模板，推荐使用「从模板复制」，可以节省大量配置时间。
:::

### 编辑与设计

每个主题卡片提供以下操作：

- **编辑**：修改模板名称、描述等基本信息
- **设计**：打开可视化页面设计器，拖拽配置页面区块和布局
- **复制**：快速复制一份模板
- **删除**：删除不再使用的模板

## 2. 页面设计器

点击主题卡片的 **设计** 按钮，进入可视化页面设计器（Builder Editor）。

在设计器中可以：

- 添加和排列页面区块（如轮播图、商品列表、分类导航等）
- 配置每个区块的内容和样式参数
- 实时预览页面效果

设计器的修改保存后即时生效。

## 3. 给子域名绑定主题

进入 **域名管理 → 一级域名**，展开目标一级域名，在子域名列表中：

1. 点击目标子域名行内的 **主题** 按钮
2. 在弹窗中搜索并选择要绑定的主题模板
3. 保存

绑定后，该子域名的商城前台将使用所选主题进行渲染。

:::warning 注意
更换主题后页面布局会立即变化。建议先在非生产子域名上预览确认后再应用到正式域名。
:::
