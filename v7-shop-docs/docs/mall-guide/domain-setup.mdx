# 域名配置

域名是商城站点的入口。系统使用**一级域名 + 子域名**两层结构管理站点。

## 基本概念

| 概念 | 说明 | 示例 |
|------|------|------|
| 一级域名 | 购买的顶级域名 | `example.com` |
| 子域名 | 一级域名下的二级域名记录 | `us.example.com` |
| 国家 | 每个子域名绑定一个国家，决定语言、货币 | 美国 → 英语 / USD |

一个一级域名下可以创建多个子域名，每个子域名对应一个国家/语言版本的商城。

## 1. 添加一级域名

进入管理后台，点击左侧菜单 **域名管理 → 一级域名**。

1. 点击顶部 **添加** 按钮
2. 填写域名（如 `example.com`）
3. 选择用途为 **网站**
4. 保存

保存后，域名会出现在列表中。此时可以在域名注册商处将域名 DNS 解析指向服务器 IP。

## 2. 创建子域名

在一级域名列表中，展开目标域名的行，进入子域名列表。

1. 点击一级域名行内的 **新增** 按钮
2. 填写以下字段：
   - **域名记录**（必填）：子域名前缀，如 `us`（最终访问地址为 `us.example.com`）
   - **国家**（必填）：选择该子域名对应的国家，如「美国」

:::warning 注意
国家一旦设定后**不可修改**，请确认后再保存。语言和货币会根据所选国家自动填充。
:::

3. 保存后，系统自动添加 DNS 解析记录

## 3. SSL 证书

保存子域名后，系统会自动为该子域名申请 SSL 证书。证书申请过程中，列表会显示排队/申请中状态，通常几分钟内完成。

## 4. 解析配置

在一级域名行内点击 **解析** 下拉菜单，选择 **新模板** 为子域名生成 Nginx 配置。

完成以上步骤后，子域名即可通过 HTTPS 访问（此时页面内容为空，需继续配置主题和商品）。
