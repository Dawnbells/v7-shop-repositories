# ADMIN-V1.0.26 发布说明

## 版本信息

- **版本区间**：`ADMIN-V1.0.25` ~ `ADMIN-V1.0.26`
- **发布日期**：2026-04-26
- **提交范围**：`83bfa1b` ~ `30727bc`

## 核心变更

### 广告投放与像素管理

- 新增广告投放配置能力，子域名绑定商品时支持按平台、像素和落地页拆分配置，并提供智能导航与平台保护。
- 像素追踪列表的转化事件展示优化为“中文（英文）”格式，便于运营人员识别事件含义。
- SPU 搜索下拉框对已绑定项置灰，并展示“已绑定”提示，降低重复绑定风险。
- 支持新增并绑定嵌入像素。
- 新增 Taboola、Bigo 像素平台支持。
- 优化像素转化跟踪逻辑，并避免风控页面触发像素事件。

### 域名与 DNS

- 子域名创建支持 `NUXT_MALL` 类型，创建时自动校验证书并写入 Nginx 配置。
- 新增 GoDaddy、Namecheap DNS 解析支持。
- Nginx 配置模板支持 `proxy_busy_buffers_size` 参数。
- 新增 `NUXT_MALL` 类型的 Nginx SSR 优化配置模板。
- 合并 Nginx 配置模板，并将 upstream 改为可配置。
- 修复子域名删除时误删 Nginx 配置的问题，并优化列表展示优先级。
- 修复添加子域名时页面全屏白色闪烁问题。

### Mall 商城配置联动

- 子域名绑定商品时支持广告投放、像素与落地页配置联动。
- Mall 商城模板使用教程同步加入文档站点。
- 斗篷策略优先使用 SPU 投放设置，避免错误读取一级域名配置。

### 订单同步与商城管理

- 第三方商城新增币种模式配置，支持 `shop_money` 与 `presentment_money`。
- 第三方商城编辑表单增加币种模式选择器。
- Shopline 订单同步集成商品 Metafield 元字段。
- 修复 Shopline 订单同步中 `skuId` 始终为 0、新订单判断不准确、SKU 名称来源错误等问题。
- 同步游标改为原子 `UPDATE`，减少乐观锁冲突。
- 第三方商城启用软删除，`handle` 和 `token` 字段增加唯一约束。

### 后台体验与稳定性

- Token 使用记录表格增加提交用户列。
- 员工管理改为伪删除，并在删除前执行清理逻辑。
- 修复地址字段拼接逻辑，确保地址信息完整。
- 修复 Metafield 归属人查询的懒加载异常。

## 修复与优化

- 修复 Nginx 配置模板类型为空时未设置默认值的问题。
- 修复订单商品字段映射和 `BeanUtil` 类型转换异常。
- 优化订单同步逻辑，移除无用字段与冗余查询。
- 精简 Cursor 规则文件，统一规则职责。

## 影响范围

- **后台前端**：域名管理、子域名绑定商品、像素账户、第三方商城、Token 使用记录、员工管理。
- **后端服务**：DNS 服务、Nginx 配置生成、第三方商城同步、像素账户、子域名绑定、订单同步。
- **商城前台**：投放配置、像素埋点、斗篷策略与商城模板文档。
