# MALL-V0.0.3 发布说明

## 版本信息

- **版本区间**：`MALL-V0.0.2` ~ `MALL-V0.0.3`
- **发布日期**：2026-04-26
- **提交范围**：`ace5006` ~ `30727bc`

## 核心变更

### 商城前台与购买链路

- 购买按钮组件支持在原按钮滚动不可见时展示底部悬浮购买栏。
- 悬浮购买栏支持三维度风格配置，便于不同商城模板按投放场景调整展示。
- 统一结算流程，移除直接下单模式，收银台价格加载增加骨架占位。
- 修复收银台表单输入框在窄容器下不自适应的问题。
- 修复购物车数量累加错误和商品名称字段错误。
- 修复规格选择样式溢出问题，并优化文字换行效果。
- 禁用手动输入地址配置项，收敛下单地址填写方式。

### 像素与广告投放

- 支持嵌入像素，并新增 Taboola、Bigo 像素能力。
- 优化 Google、Meta、TikTok 等像素转化跟踪逻辑。
- 避免风控页面触发像素事件，减少无效转化上报。
- 子域名绑定商品时支持广告投放配置，与管理后台投放能力联动。

### 域名、路由与斗篷策略

- 斗篷策略优先使用 SPU 投放设置，而不是一级域名配置。
- 收敛服务端中间件路由判断，清理调试日志。
- 增加统一路由匹配工具，优化商品页、落地页、结账页、订单页等中间件判断。
- 新增 `NUXT_MALL` 类型 Nginx SSR 优化配置模板，并支持子域名创建时自动校验证书和写入 Nginx 配置。

### 性能与稳定性

- 修复收银台价格查询全表扫描导致的明显延迟，并增加耗时诊断日志。
- 修复临时订单插入缺少 `is_reviewed` 字段导致下单失败的问题。
- 同步游标改为原子 `UPDATE`，减少订单同步并发冲突。
- 修复 Shopline 订单同步中 SKU、商品名和新订单判断相关问题。

### 运营后台配套能力

- 新增地址库管理页面，支持省、市、区、邮编搜索。
- 新增通知管理与通知组件轮询交互。
- 域名管理增加 SSL 证书和到期时间列的三态排序。
- 域名巡检任务增加本地脏数据清理，域名删除时自动清理证书文件和 Nginx 配置。
- 第三方商城订单同步重构为临时表与并行拉取流程，并新增第三方商城订单同步文档。
- 第三方商城新增币种模式配置，支持 `shop_money` 与 `presentment_money`。

## 文档变更

- 初始化 V7 Shop 文档站点。
- 新增 Mall 商城模板使用教程。
- 新增第三方商城订单同步操作文档。

## 影响范围

- **商城前台**：商品页、结账页、订单结果页、购物车、像素埋点、服务端中间件。
- **管理后台**：地址库、通知、域名管理、子域名绑定商品、第三方商城订单同步、像素账户。
- **后端服务**：订单同步、域名巡检、Nginx 配置、DNS 服务、临时订单、第三方商城配置。
