3. [历史订单同步操作](./history-sync) — 按时间段拉取历史订单
4. [暂停与删除订单同步](./pause-delete) — 暂停或移除店铺同步
5. [常见问题](./faq) — SKU 匹配规则、归属人规则、支付状态对照等
