# 常见问题

## SKU 名称匹配规则

同步订单时，系统会自动将 Shopline 订单中商品的 SKU 编码与系统商品库进行匹配。

### 匹配逻辑

1. **第一步：按部门匹配** — 在第三方商城归属人所在部门的所有 SKU 中查找匹配的编码
2. **第二步：按归属人匹配** — 如果部门下未找到任何匹配，则在归属人名下的 SKU 中查找

:::info 匹配说明
- SKU 编码 **区分大小写**，必须与系统中的完全一致
- 匹配时会自动去除编码前后的空格
- 如果所有编码都未匹配到，订单仍会正常同步，但商品的 SKU 名称为空
- 部分匹配的情况：已匹配的 SKU 会关联商品信息，未匹配的保留原始编码
:::

### 示例

假设 Shopline 订单中有 3 个商品，SKU 编码分别为 `A001`、`B002`、`C003`：

| 步骤 | 查询范围 | 结果 |
|------|---------|------|
| 1 | 归属人所在部门的所有 SKU | 找到 `A001` 和 `B002` |
| 2 | 跳过（步骤 1 已有结果） | — |
| 最终 | `A001` `B002` 关联系统商品，`C003` 保留原始编码 | — |

:::tip
如果步骤 1 完全没有命中任何 SKU，才会执行步骤 2。两步之间是 **整体降级**，不是逐个降级。
:::

## 订单归属人规则

同步订单的归属人按以下优先级确定：

| 优先级 | 来源 | 说明 |
|:------:|------|------|
| 1 | **归属人账号**（`owner_telephone`） | Shopline 商品元字段中的登录手机号，匹配系统用户 |
| 2 | **归属人**（`owner_name`） | Shopline 商品元字段中的用户名，匹配系统用户 |
| 3 | **第三方商城归属** | 第三方网站管理中配置的店铺归属人（默认值） |

:::info
- 归属人信息从订单中 **第一个商品** 的元字段读取
- 如果元字段中的账号或姓名在系统中找不到对应用户，会降级到下一优先级
- 同一商城有多个归属人时，建议使用 `owner_telephone` 或 `owner_name` 元字段区分
:::

## 支付状态对照

Shopline 的财务状态与系统支付状态的对应关系：

| Shopline 状态 | 系统状态 | 说明 |
|--------------|---------|------|
| `unpaid` | 待付款 | 订单未支付 |
| `authorized` | 已授权 | 支付已授权但未扣款 |
| `pending` | 处理中 | 支付处理中 |
| `partially_paid` | 部分付款 | 仅支付了部分金额 |
| `paid` | 已付款 | 支付完成 |
| `partially_refunded` | 部分退款 | 已退还部分金额 |
| `refunded` | 已退款 | 全额退款 |

如果 Shopline 返回的状态不在上述列表中，默认按 **待付款** 处理。

## 订单同步按钮不可点击

**原因**：店铺的授权状态不是「已连接」。

**解决方法**：
1. 点击操作列的 **「编辑」**
2. 检查 **HANDLE** 和 **访问令牌** 是否正确
3. 修改后点击 **「保存」**，系统会重新触发授权验证

---

## 授权状态显示「连接异常」

**可能原因**：
- 访问令牌已过期或被吊销（有效期三年）
- HANDLE 填写错误（不要包含 `.myshopline.com` 后缀）
- Shopline 店铺已关闭或 API 权限不足
- 网络连接异常

**解决方法**：
1. 登录 Shopline 后台确认店铺状态正常
2. 检查应用的 API 权限是否包含「订单读取」
3. 如令牌过期，重新生成访问令牌
4. 将新令牌更新到系统中并保存

---

## 同步的订单找不到

**排查步骤**：
1. 确认同步任务是否已完成 — 查看任务栏中的进度是否显示完成
2. 前往 **审单** 列表 — 使用「订单平台 = SHOPLINE」筛选
3. 检查时间范围 — 确认设置的时间范围覆盖了目标订单在 Shopline 中的**创建时间**
4. 检查是否已处理 — 订单可能已从审单队列中被处理转入正式订单

---

## 订单金额不正确

**可能原因**：币种模式设置不当。

**解决方法**：
1. 进入 **第三方网站管理**，编辑目标店铺
2. 调整 **币种模式**：
   - **店铺结算币种**（SHOP_MONEY）— 使用店铺统一结算金额
   - **订单展示币种**（PRESENTMENT_MONEY）— 使用客户看到的展示金额
3. 保存后重新同步受影响时间段的订单

---

## 同步任务长时间未完成

**可能原因**：
- 时间范围过大，订单数量较多
- 网络连接不稳定

**处理方法**：
1. 每页拉取 100 条订单，大量订单需要数分钟，请耐心等待
2. 如确认卡住，可缩小时间范围分批同步
3. 首次同步建议按月分批拉取，避免单次任务数据量过大

---

## 订单重复导入

系统通过 Shopline 的原始订单 ID 进行去重。**已同步过的订单不会重复导入**，重复订单会自动跳过并记录日志。

如果同一时间段多次手动同步，不会产生重复数据。
