# Shopify 订单同步

通过 Shopify 应用 **VantaSite Order Sync**，把 Shopify 店铺的订单同步到 VantaSite 的审单列表。应用免费，只读取订单和商品数据，不会修改店铺中的任何内容。

连接后，新订单会近实时（通常 1 分钟内）进入审单列表；同步规则（商品元字段补全、SKU 匹配、归属人、支付状态）与 Shopline 一致。

## 开始之前

- 你需要能在 Shopify 店铺中安装应用（店主或有应用管理权限的员工）。
- 你需要有 VantaSite 后台「第三方商城」的新增权限。
- 店铺绑定后，**归属人是完成绑定时登录的 VantaSite 账号**，未匹配到元字段归属人的订单默认归属此人。

应用申请的权限：

| 权限 | 用途 |
| --- | --- |
| `read_orders` | 读取订单 |
| `read_products` | 读取商品元字段，用于补全品名、SKU 和归属人 |

应用暂不申请 `read_all_orders`，因此手动同步历史订单时**只能选择最近 60 天**。

收货人姓名、地址、电话、邮箱属于 Shopify 的受保护客户数据，我们只用于审单、发货、面单打印和风控，处理方式见 [隐私政策](../privacy-policy.mdx)。

## 方式一：从 VantaSite 后台连接（推荐）

1. 进入 VantaSite 后台 **第三方商城**，点击 **添加**。
2. 按下表填写：

   | 字段 | 填写内容 |
   | --- | --- |
   | 店铺名称 | 随意填写，会显示在订单来源里 |
   | 商城类型 | 选择 **SHOPIFY** |
   | 接入方式 | 选择 **公开应用** |
   | HANDLE | 店铺地址 `xxx.myshopify.com` 中的 `xxx` |
   | 币种模式 | 见下方 [币种模式](#币种模式) |

3. 点击 **连接 Shopify**，页面会跳转到 Shopify。
4. 在 Shopify 中确认应用请求的权限，点击安装。
5. 授权完成后自动回到 VantaSite 后台，页面提示 **已连接**，点击 **前往第三方商城**，列表中该店铺的授权状态显示 **已连接**。

**HANDLE 怎么找**：登录 Shopify 店铺后台，浏览器地址形如 `admin.shopify.com/store/xxx`，其中的 `xxx` 就是 HANDLE。直接粘贴 `https://xxx.myshopify.com` 也可以，系统会自动截取。不要填店铺绑定的自定义域名。

## 方式二：从 Shopify App Store 或店铺后台打开

适合商家先在 Shopify 中安装了应用的情况。

1. 在 Shopify App Store 搜索 **VantaSite Order Sync** 并安装，或在 Shopify 店铺后台的 **应用** 中打开已安装的应用。
2. 页面显示「Connect your VantaSite admin」，在「Enter your VantaSite admin URL」中填入你的 VantaSite **总后台地址**（形如 `admin.xxx.com`，即登录总后台时浏览器地址栏中的域名），点击继续。
3. 如未登录，先登录 VantaSite 后台。
4. 登录后系统自动完成绑定，页面提示 **已连接**。在 **第三方商城** 列表中可以看到该店铺，店铺名称默认为 HANDLE，币种模式默认为店铺结算币种，可通过 **编辑** 修改。

:::info 说明
从第 2 步开始需在 30 分钟内完成绑定。超时后回到 Shopify 店铺后台，重新打开应用即可。

如果页面提示「该店铺已连接到 VantaSite」，说明店铺已经绑定，直接登录后台查看即可。
:::

## 确认同步生效

1. 在 Shopify 店铺下一个测试订单。
2. 约 1 分钟内，进入 **审单** 列表，用「订单平台 = SHOPIFY」筛选，应能看到这笔订单。

新订单、订单更新和订单取消由 Shopify 实时推送；系统另外约每 15 分钟对账一次，补齐可能遗漏的订单，不会产生重复订单。

自动同步只处理**绑定之后**创建的订单，之前的订单需要手动同步。

## 同步历史订单

1. 在 **第三方商城** 列表中，点击目标店铺操作列的 **订单同步**。
2. 选择订单创建时间的范围（最早为 60 天前），系统会先显示该范围内的订单数量。
3. 确认后提交，任务在后台执行，可在右上角 **任务中心** 查看进度。

重复同步同一时间段不会产生重复订单，已存在的订单会被更新。

## 币种模式

| 选项 | 含义 | 适用情况 |
| --- | --- | --- |
| 店铺结算币种 | 按店铺设置的币种记录金额 | 店铺只用一种币种，或希望统一币种核算 |
| 订单展示币种 | 按客户下单时看到的币种记录金额 | 店铺开了多币种，希望保留客户实际支付的币种 |

## 暂停、恢复与删除

- **暂停**：关闭列表中的状态开关，同步停止。
- **恢复**：重新打开状态开关，系统会在下一次对账时补齐暂停期间的订单。
- **删除**：点击操作列的 **删除**，移除该店铺的同步配置，已同步的订单不受影响。如不再使用，请同时在 Shopify 店铺后台卸载应用。

## 重新连接

授权状态显示 **已断开** 或 **连接异常** 时，点击操作列的 **重新连接**，按方式一的第 3–5 步重新授权即可。原有的同步记录和订单会保留。

## 卸载应用

在 Shopify 店铺后台 **设置 → 应用** 中卸载 VantaSite Order Sync 后：

- VantaSite 中该店铺显示 **已断开**，同步停止，访问令牌被清除；
- 已同步的订单保留；
- 约 48 小时后 Shopify 会通知我们删除店铺数据，系统将对该店铺订单的收货人姓名、电话、邮箱、详细地址、邮编和客户 IP 进行脱敏，商品、金额、状态以及国家/省份/城市保留。

卸载后重新安装并绑定，会恢复原来的店铺记录。

## 商品元字段

在 Shopify 商品上配置元字段后，同步订单时会自动带上中文品名、面单品名、SKU 编码和归属人。

1. 进入 Shopify 店铺后台 **设置 → 自定义数据 → 商品**。
2. 点击 **添加定义**，按下表逐个创建。命名空间和密钥必须与表中一致，类型都选 **单行文本**。

   | 字段名称 | 命名空间和密钥 | 作用 |
   | --- | --- | --- |
   | 中文品名 | `xyz.cn_product_name` | 订单商品的中文品名 |
   | 面单品名 | `xyz.waybill_product_name` | 打印面单时使用的品名 |
   | 归属人账号 | `xyz.owner_telephone` | 归属人的登录手机号 |
   | 归属人 | `xyz.owner_name` | 归属人的名字 |
   | 高优先级 SKU 编码 | `xyz.sku_code_high` | 覆盖商品自身的 SKU 编码 |
   | 备用 SKU 编码 | `xyz.sku_code` | 商品没有填 SKU 时使用 |

   按需添加，不需要的可以不建。

3. 打开商品详情页，在页面底部的元字段区域填写对应的值并保存。之后同步的订单会自动使用这些值。

**SKU 编码**按以下顺序取第一个有值的：

1. 元字段 `sku_code_high`
2. 商品规格上填写的 SKU
3. 元字段 `sku_code`

取到编码后，系统先在店铺归属人所在部门的 SKU 中匹配；部门下一个都没匹配到时，再在归属人名下的 SKU 中匹配。编码区分大小写。匹配不到时订单照常同步，只是 SKU 名称为空。

**订单归属人**按以下顺序确定，从订单里第一个商品的元字段读取：

1. `owner_telephone` 对应的系统用户
2. `owner_name` 对应的系统用户
3. 店铺归属人（默认）

## 支付状态对照

| Shopify 支付状态 | 系统支付状态 |
| --- | --- |
| `pending` | 处理中 |
| `authorized` | 已授权 |
| `partially_paid` | 部分付款 |
| `paid` | 已付款 |
| `partially_refunded` | 部分退款 |
| `refunded` | 已退款 |
| `voided` | 待付款 |

如果 Shopify 返回的状态不在上述列表中，默认按 **待付款** 处理。

## 常见问题

### 提示「该店铺已绑定到其他账号」

同一个 HANDLE 只能绑定一次，且 Shopify 与 Shopline 店铺共用这个限制。请联系已绑定的账号解绑后再连接。

### 输入后台地址后提示无法识别

请填写 VantaSite 总后台地址，形如 `admin.xxx.com`（登录总后台时浏览器地址栏中的域名），不要填店铺前台域名或 Shopify 店铺地址。

### 提示链接已过期

绑定链接 30 分钟内有效。回到 Shopify 店铺后台重新打开应用，或改用方式一从 VantaSite 后台连接。

### 历史订单数量比 Shopify 后台少

应用暂未获得 `read_all_orders` 权限，只能同步最近 60 天的订单。

### 订单的收货人信息显示为 `[redacted]` 或为空

订单已按保留期规则或 Shopify 的删除请求脱敏（见 [隐私政策](../privacy-policy.mdx)），脱敏后无法恢复。

### 订单金额或币种不对

币种模式选择不当。编辑店铺调整币种模式，保存后重新同步受影响时间段的订单。

### 同步的订单找不到

1. 在任务中心确认同步任务已完成。
2. 在审单列表用「订单平台 = SHOPIFY」筛选。
3. 确认选择的时间范围覆盖了订单在 Shopify 的**创建时间**。
4. 订单可能已经审核通过，转入了正式订单列表。

### 订单没有中文品名或归属人不对

1. 确认元字段的命名空间是 `xyz`，密钥与上表完全一致。
2. 确认元字段填在**商品**上，而不是商品规格上。
3. 归属人账号或名字在系统中找不到对应用户时，会使用店铺归属人。

### 手动同步任务刚开始时显示「正在连接Shopline」

这是任务的通用提示文案，不影响同步，随后会变为同步进度。

## 附录：组织内自用（凭证模式）

如果店铺与你的 Shopify 应用属于**同一个 Shopify 组织**，也可以不安装公开应用，改用自建应用的 Client ID 和 Client Secret 连接。凭证模式由系统每分钟轮询新订单。

:::warning 注意
应用必须与店铺属于同一个 Shopify 组织，否则无法获取访问令牌。Shopify 自 2026 年 1 月 1 日起不再支持在店铺后台新建自定义应用，请使用 Dev Dashboard。
:::

### 1. 创建应用并配置权限

1. 打开 [Shopify Dev Dashboard](https://dev.shopify.com/dashboard)，在 **Apps** 中点击 **Create app**，选择 **Start from Dev Dashboard**，名称不限。
2. 进入应用的 **Versions** 页面新建版本，**App URL** 填任意可访问地址，**Webhooks API version** 选最新版本。
3. 在 **Scopes** 中填入权限，然后点击 **Release** 发布版本：

   | 权限 | 是否必选 | 用途 |
   | --- | --- | --- |
   | `read_orders` | 必选 | 读取订单 |
   | `read_products` | 推荐 | 读取商品元字段 |
   | `read_all_orders` | 按需 | 同步 60 天以前的历史订单 |

组织内自用的应用默认可以读取收货人信息。如果同步到的订单没有收货人信息，请在应用的 **API access requests** 中检查 **Protected customer data access** 是否已开通。

### 2. 安装应用并复制凭证

1. 在应用首页的 **Installs** 卡片中点击 **Install app**，选择要同步订单的店铺并安装。
2. 进入应用的 **Settings** 页面，复制 **Client ID** 和 **Client secret**。Client Secret 等同于密码，不要外传。

### 3. 在系统中添加店铺

进入 VantaSite 后台 **第三方商城**，点击 **添加**，商城类型选 **SHOPIFY**，接入方式选 **凭证模式**：

| 字段 | 填写内容 |
| --- | --- |
| 店铺名称 | 随意填写 |
| HANDLE | `xxx.myshopify.com` 中的 `xxx` |
| Client ID | 上一步复制的 Client ID |
| Client Secret | 上一步复制的 Client secret |
| 币种模式 | 店铺结算币种或订单展示币种 |

保存时系统会验证连接，验证通过后授权状态显示 **已连接**，并自动同步之后新增的订单。

:::info 说明
访问令牌由系统使用 Client ID 和 Client Secret 自动获取，有效期 24 小时，到期前自动更新。在 Shopify 重新生成 Client Secret 后，需要编辑店铺填入新的值；编辑时 Client Secret 不回显，留空表示不修改。
:::

### 凭证模式常见问题

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 无法获取Shopify访问令牌 | HANDLE 填成自定义域名、凭证复制不完整、应用未安装到店铺或不属于同一组织 | 逐项检查后重新保存 |
| 无法连接到Shopify | HANDLE 填错或服务器网络无法访问 Shopify | 检查 HANDLE |
| 应用缺少订单读取权限(read_orders) | 应用版本没有勾选 `read_orders` | 新建版本加上权限并发布，然后编辑店铺重新保存 |
| Client ID/Secret无效或应用权限不足 | Client Secret 被重新生成，或应用被卸载 | 确认应用仍已安装，编辑店铺填入新的 Client Secret |

出现连接异常后店铺会被自动停用。修复后编辑并保存店铺，再把状态开关打开。
