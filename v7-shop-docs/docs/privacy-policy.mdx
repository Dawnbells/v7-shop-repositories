# 隐私政策

**生效日期：2026 年 10 月 22 日**

本隐私政策说明 VantaSite（以下简称「我们」）在商家安装并使用 Shopify 应用 **VantaSite Order Sync**（以下简称「本应用」）时，如何收集、使用、保存和删除来自 Shopify 店铺的数据。本应用免费提供，只读取订单与商品数据，用于把 Shopify 订单同步到商家自己的 VantaSite 后台。

对于店铺顾客的个人信息，商家是数据的控制方；我们按照商家的授权和指示处理这些数据。顾客如需行使个人信息相关权利，请优先联系下单的店铺，我们会配合商家处理。

## 1. 我们收集的数据

本应用只在商家授权的权限范围（`read_orders`、`read_products`）内读取数据：

| 类别 | 具体内容 |
| --- | --- |
| 订单信息 | 订单号、创建与更新时间、支付状态、发货状态、取消状态与原因、金额与币种、折扣、运费、税费、支付网关名称、订单备注与标签、订单来源与落地页 |
| 收货人信息 | 收货人及账单联系人的姓名、电话、邮箱、详细地址、邮编、国家/省份/城市 |
| 顾客技术信息 | 下单时的顾客 IP 地址与浏览器 User-Agent |
| 商品信息 | 订单中的商品名称、规格、SKU、数量、单价，以及商品上命名空间为 `xyz` 的元字段（如中文品名、面单品名、SKU 编码、归属人） |
| 店铺信息 | 店铺域名（handle）、访问令牌、已授予的权限范围、安装与卸载时间 |

我们不直接向顾客收集任何信息，也不在商家的店铺前台放置 Cookie 或追踪脚本。

此外，商家团队在 VantaSite 后台查看或导出 Shopify 订单的收货人信息时，系统会记录访问日志（操作人、时间、动作、订单编号），用于安全审计。

## 2. 数据来源

- **Shopify Admin API**：商家授权后，我们通过 Shopify Admin API（GraphQL）读取订单与商品数据，包括商家手动发起的历史订单同步（最近 60 天）和约每 15 分钟一次的对账。
- **Shopify Webhook**：订单创建、更新、取消，以及应用卸载、数据删除和数据访问请求时，Shopify 会向我们推送通知。我们会校验每条通知的签名（HMAC），校验失败的通知不予处理。

## 3. 数据用途

我们仅将上述数据用于为商家提供以下服务：

- **审单**：在商家的 VantaSite 审单列表中展示订单，供商家团队核对地址、匹配 SKU、审核放行；
- **发货**：根据收货人信息安排履约与物流；
- **面单**：打印快递面单所需的收货人姓名、电话、地址和面单品名；
- **风控**：结合顾客 IP、User-Agent 等信息识别异常或高风险订单。

我们不会将这些数据用于广告投放、营销推送或用户画像，也不会用于上述服务以外的目的。

## 4. 数据共享

- 我们**不出售**任何来自 Shopify 的数据，也**不与第三方共享**这些数据供其自行使用。
- 数据只在商家自己的 VantaSite 账号内，供商家授权的团队成员按其后台权限查看和使用。
- 我们运行服务所使用的云服务器和数据库仅用于存储和处理数据，由我们管理。
- 如法律法规或有权机关依法要求，我们可能在必要范围内披露相关数据，并在法律允许时通知商家。

## 5. 数据保留与脱敏

- **保留期**：订单在最后一次更新后满 **12 个月**，系统会自动对其收货人信息进行脱敏（保留期可由运营方配置）。脱敏内容包括收货人姓名、电话、邮箱、详细地址、邮编和顾客 IP；商品、金额、订单状态以及国家/省份/城市会保留，用于对账和统计。
- **访问日志**：收货人信息的查看与导出日志保留 12 个月后删除。
- **卸载应用**：商家卸载本应用后，店铺在 VantaSite 中显示为「已断开」，我们停止同步并清除访问令牌；已同步的订单保留在商家账号中，直到收到下文所述的删除请求或达到保留期。

## 6. 删除请求与数据访问请求

我们按照 Shopify 的隐私合规要求处理以下三类请求，并在收到请求后 **30 天内** 完成处理：

| 请求 | 触发时机 | 我们的处理 |
| --- | --- | --- |
| `shop/redact`（店铺数据删除） | 商家卸载应用约 48 小时后由 Shopify 发送 | 对该店铺所有已同步订单的收货人姓名、电话、邮箱、详细地址、邮编和顾客 IP 进行脱敏，并删除该店铺的访问凭证 |
| `customers/redact`（顾客数据删除） | 顾客向商家提出删除请求后由 Shopify 发送 | 对该顾客在该店铺的相关订单进行同样的脱敏 |
| `customers/data_request`（顾客数据访问） | 顾客向商家申请查看其数据后由 Shopify 发送 | 通知该店铺在 VantaSite 中的归属运营人员，由其在 30 天内导出相关订单数据并交付商家，再由商家提供给顾客 |

每次处理都会留存处理记录（请求类型、时间、涉及订单数量、处理状态），以便追溯。

## 7. 安全措施

我们采取合理的技术和管理措施保护数据，包括：

- 与 Shopify 之间的数据交换以及后台访问使用 HTTPS 加密传输；
- 校验 Shopify 推送通知和授权回调的签名，安装授权使用一次性、短时有效的票据；
- 访问令牌只保存在服务端，不在后台界面回显，不写入日志；
- 后台按角色和数据范围进行权限控制，商家只能访问自己账号下的订单；
- 对收货人信息的查看与导出记录访问日志；
- 只申请订单与商品的只读权限，不修改商家店铺中的任何数据。

任何安全措施都无法完全消除风险。如发生影响商家数据的安全事件，我们会按适用法律的要求通知受影响的商家。

## 8. 顾客的权利

根据所在地区的法律（例如 GDPR、CCPA），顾客可能享有访问、更正、删除其个人信息等权利。由于顾客的数据来自商家店铺，请顾客先向下单的商家提出请求；我们收到 Shopify 转达的请求后，会按第 6 节处理。如顾客直接联系我们，我们会将请求转交给相应商家。

## 9. 政策更新

我们可能根据产品功能或法律要求更新本政策。更新后的版本会发布在本页面并标注新的生效日期；如有重大变更，我们会通过 VantaSite 后台或电子邮件通知商家。
